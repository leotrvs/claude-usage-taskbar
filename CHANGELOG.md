# Changelog

## 1.4.2

- Blue is now the default color template, and Ring the default icon style
- Gauge has a wider arc and a smaller number that stays clear of it
- The weekly pace is now shown as a percentage

## 1.4.1

- Slightly stronger blue in the Blue color template

## 1.4.0

- Hovering the chart shows the time, the usage and how much it rose since the previous reading

## 1.3.0

- Inter font built into the app, so the panel looks the same on every PC

## 1.2.0

- Animated mascot with its laptop, included with the app

## 1.1.0

- New icons with no background: Gauge with the number inside a dial, Ring and Needle
- Green, Blue and Purple color templates, and a Graphite or Black panel
- Check for updates button, and an install link in the panel
- Short fade and slide when the panel opens and closes

## 1.0.0

- First release
- 5-hour and weekly usage in the Windows taskbar, with Gauge and Outline icon styles
- Choice of showing both icons or only one
- Optional usage alerts, a 12-hour chart and a pace forecast
- Optional local mascot image
- Usage data from the official Claude Code status line, with no access to login or token
- English and Brazilian Portuguese
- One-click install with Desktop and Start menu shortcuts
- Signed automatic updates
