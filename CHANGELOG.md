# Changelog

## 1.5.3

- The update check when the app opens installs an update right away, and a notification confirms it
- The app shows when it last checked for updates
- Notifications is now one option, for usage alerts and installed updates
- Settings, Appearance and Quit are now one row of buttons
- Icon styles moved into Appearance, and each page has its own height
- Selected options have a stronger orange
- The weekly limit sits closer to the session limit
- Close widget is now called Quit
- Smoother animations on toggles, selectors, hover and page changes

## 1.5.2

- A stronger orange accent in the panel
- Larger taskbar numbers in Gauge, with a thinner line that gives them room
- Updates are checked 5 seconds after the app opens and then every hour, and one found with the panel open installs when it closes

## 1.5.1

- Usage is now read from Claude Code's `/usage` command every 2 minutes, so it updates with no terminal open
- Taskbar numbers are now exactly centered, with a new digit design that stays clear of the line
- At 100% and 125% display scaling, icons are one pixel smaller, so the circle has a center pixel
- Classic is the default mascot again, and comes first in the selector
- The README is now also in Spanish and Russian, with clearer steps and more pictures

## 1.5.0

- Taskbar numbers are drawn pixel by pixel, so they stay sharp at 16 pixels
- The update row turns while checking and shows a download icon when an update is ready
- New pixel mascot drawn by the app, which sleeps, rests, works, gets tired and falls over with your usage
- Mascot selector in Appearance, with a Christmas hat and the Classic animation

## 1.4.2

- Blue is now the default color template, and Ring the default icon style
- Gauge has a wider arc and a smaller number that stays clear of it
- The weekly pace is now shown as a percentage

## 1.4.1

- Slightly stronger blue in the Blue color template

## 1.4.0

- Hovering the chart shows the time, the usage and how much it rose since the previous reading

## 1.3.0

- Inter font built into the app, so the panel looks the same on every PC

## 1.2.0

- Animated mascot with its laptop, included with the app

## 1.1.0

- New icons with no background: Gauge with the number inside a dial, Ring and Needle
- Green, Blue and Purple color templates, and a Graphite or Black panel
- Check for updates button, and an install link in the panel
- Short fade and slide when the panel opens and closes

## 1.0.0

- First release
- 5-hour and weekly usage in the Windows taskbar, with Gauge and Outline icon styles
- Choice of showing both icons or only one
- Optional usage alerts, a 12-hour chart and a pace forecast
- Optional local mascot image
- Usage data from the official Claude Code status line, with no access to login or token
- English and Brazilian Portuguese
- One-click install with Desktop and Start menu shortcuts
- Signed automatic updates
